Dispatch, faults and recovery

    Operating-system concepts
    POSIX threads
    One dispatcher consumes arrivals. Every active assignment gets a charging worker.
    Mutex and counting semaphore
    A mutex protects station state. The semaphore counts healthy, unused chargers.
    Priority scheduling
    Emergency, low battery (SOC ≤20%), premium or fleet, reserved, then normal. Requests in a class retain arrival order.
    Resource management
    Power is shared equally, with a 22 kW charger ceiling. A new assignment requires at least 3 kW per active slot.
    Interprocess communication
    The local HTTP gateway exchanges commands and snapshots with the C++ engine through pipes.
